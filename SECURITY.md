# Security Policy

## Supported Versions

Since this is a simple static HTML/CSS frontend project, only the latest version on the `main` branch is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not disclose it publicly or create a public issue. 

Instead, please report it privately by contacting me:
- **Email:** disanalamofficial@gmail.com
- **LinkedIn:** https://www.linkedin.com/in/disanalam

Please include the following details in your report:
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- The potential impact.

I will review the report and work on a fix as soon as possible.
